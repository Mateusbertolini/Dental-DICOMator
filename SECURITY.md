# Security policy

Security fixes target the latest release. Report vulnerabilities privately at:

https://github.com/Mateusbertolini/Dental-DICOMator/security/advisories/new

Never include credentials, PHI, patient identifiers, or identifiable clinical DICOM data.

Dental DICOMator creates synthetic research and education data. It is not a medical device and is not for diagnosis or patient care without independent validation and required approvals.
